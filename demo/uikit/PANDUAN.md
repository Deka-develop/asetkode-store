# Panduan Penggunaan UI Kit E-Commerce & SaaS

1. Buka `index.html` di browser untuk melihat seluruh komponen secara interaktif (termasuk Dark/Light Mode & Toggle Harga).
2. Klik tombol **Salin Kode HTML** pada komponen yang diinginkan.
3. Sertakan `tokens.css` di proyek Anda, lalu ubah nilai warna pada `:root` untuk menyesuaikan identitas brand Anda.
