# Panduan Penggunaan Template Company Profile & Digital Agency

1. **Cara Edit Cepat (Tanpa Coding):**
   Buka file `config.js` menggunakan Notepad / VS Code, lalu ubah:
   - `brandName`, `brandTagline`, `heroTitle`, `heroSubtitle`
   - `whatsappNumber` (format `628...`) dan `email`
   - Daftar `services`, `portfolio`, `packages`, dan `faqs`
2. **Cara Menjalankan:**
   Klik 2x file `index.html` untuk melihat langsung di browser, atau unggah seluruh folder ini ke hosting / cPanel / GitHub Pages / Netlify / Vercel.
