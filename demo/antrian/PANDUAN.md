# Panduan Program Antrian Digital & Suara Panggil

1. **Cara Menjalankan (Zero-Config):**
   - Klik 2x `Buka_Program_Antrian.bat` (atau buka `index.html` di Chrome / Edge).
   - Tidak butuh XAMPP, Apache, atau database eksternal.
2. **Cara Pakai Multi-Layar (Monitor TV + Operator):**
   - Buka program di **2 Tab / 2 Jendela Browser** (1 untuk **Panel Operator**, 1 lagi arahkan ke **Monitor TV** dan drag ke layar TV ruang tunggu).
   - Saat operator klik **Panggil Berikutnya**, layar Monitor TV otomatis ikut berubah secara real-time.
3. **Suara Panggil & Cetak Tiket:**
   - Pastikan volume perangkat aktif agar bel + suara panggil Bahasa Indonesia terdengar.
   - Di tab **Kios Ambil Tiket**, klik **Cetak Struk Tiket** untuk mencetak ke printer thermal 58mm/80mm.
